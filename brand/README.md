# Laurel Games brand files

The mark is a single bay laurel leaf, tilted, with its midrib cut through and
the gently wavy edge bay leaves have. The wordmark is Bodoni Moda (weight 500),
converted to outlines, so the SVGs need no font installed.

| File | Use |
|---|---|
| `mark.svg` | The leaf on its own. Single colour; recolour by changing `fill`. |
| `logo.svg` | Horizontal lockup, mark left of the wordmark. Ink on transparent. |
| `logo-stacked.svg` | Mark above the wordmark, centred. For square spaces. |
| `wordmark.svg` | The words alone. |
| `logo-ink.png`, `logo-stacked-ink.png` | 2× PNG, deep-blue ink on transparent, for light backgrounds. |
| `logo-ivory.png`, `logo-stacked-ivory.png` | 2× PNG, ivory on transparent, for dark backgrounds. |
| `icon-1024.png` | Ivory mark on the blue-hour sky, 1024 × 1024, for store and social profile icons. |

Colours: ink `#15205a`, ivory `#f3e9d6`, night `#1b2a5e`, lake `#3c5aa6`, glow `#f0c9a4`.

The site's `favicon.svg` and `apple-touch-icon.png` use the ivory mark on a
night-blue rounded square.
